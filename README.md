## 📖 О проекте

**Tavros** — это элегантный одностраничный сайт, разработанный в комерческих целях, личного бренда. Проект выполнен с акцентом на адаптивность и современный дизайн.

### ✨ Особенности

- 🎨 Современный и минималистичный дизайн
- 📱 Полностью адаптивная вёрстка
- ⚡ Быстрая загрузка и оптимизация
- 🖼️ Интеграция с изображениями и иконками
- 📂 Удобная структура проектов
- 🌍 Поддержка GitHub Pages (CNAME)

## 📂 Структура проекта
```bash
Tavros/
├── font/                 # Шрифты проекта
├── images/               # Изображения и иконки
├── projects/             # Страницы проектов
├── CNAME                 # Настройка домена для GitHub Pages
├── data.js               # Данные для отображения контента
├── index.html            # Главная страница
├── script.js             # Основной JavaScript
└── style.css             # Стили проекта
```
